Add the Sell Finances API as a new `finances` tool family: eleven read-only tools covering seller transactions, transaction summaries, payouts, payout details, payout summaries, seller funds summaries, transfers, per-order earnings, order earnings summaries, and billing activities. All tools require the `sell.finances` OAuth scope and honor the `EBAY_MCP_API_BASE_URL` override.
